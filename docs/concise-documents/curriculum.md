# Curriculum

## Overview

The Curriculum section is part of the **Resources** page, accessible to Super Admins. It provides a centralized place to manage curriculum entries used across the platform. Curriculums are reference data that can be assigned to classes, enrollments, and other academic structures.

---

## Accessing the Curriculum Section

- Navigate to **Resources** from the sidebar.
- Select the **Curriculums** tab from the tab bar (alongside Boards, Grades, and Subjects).

---

## Key Features

- **Curriculum Listing** — Displays all existing curriculums as individual cards, each showing the curriculum name and its creation date (day, month, and year).
- **Search** — Filter the list in real time by typing a curriculum name in the search box.
- **Add Curriculum** — Create a new curriculum entry via a modal form.
- **Edit Curriculum** — Update an existing curriculum name via a modal form.
- **Delete Curriculum** — Permanently remove a curriculum entry with a confirmation step.

---

## User Actions

### Search
- Use the **Search** bar at the top of the page.
- Type any part of a curriculum name to instantly filter the displayed list.

### Add a Curriculum
1. Click the **Add New** button (top-right of the page).
2. A modal opens with a heading **Add Curriculums**.
3. Enter the curriculum name in the input field.
4. Click **Add** to save.
- The list refreshes automatically after a successful addition.

### Edit a Curriculum
1. Click anywhere on a curriculum card.
2. An **Update Curriculum** modal opens.
3. Enter the new name in the input field.
4. Click **Update** to save changes.
- The list refreshes automatically after a successful update.

### Delete a Curriculum
1. Click the **delete icon** on a curriculum card.
2. A confirmation modal appears with the warning:
   > *"This action cannot be undone. All values associated with this field will be lost."*
3. Click **Delete** to confirm, or **Cancel** to dismiss.
- The entry is permanently removed once confirmed.

---

## Notes

- Deleting a curriculum is irreversible. All platform data linked to the deleted curriculum may be affected.
- The search filter applies only to the currently active tab (Curriculums).
- Each curriculum card displays its creation date broken down into **Day**, **Month**, and **Year**.
